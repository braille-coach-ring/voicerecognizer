# 音素マルチタスク（Frame-level Logit Max）スクラッチ学習結果（2026-10-05）

## 概要

- **目的**: 82.5%を占めていた「母音一致・子音誤認（ち↔し、つ↔す等）」を解消するため、子音（30クラス）・母音（7クラス）の分類ヘッドを並列配置し、VAD時間境界ジッターに完全耐性を持つ **Frame-level Logit Max プーリング** を導入。
- **学習方式**: `facebook/wav2vec2-base` からの完全スクラッチ学習（30エポック、Patience 6、lr 4e-5、下位4層フリーズ）
- **データ分割**: `data_splits/speaker_mixed_balanced_20261004` (Train 7,173件 / Val 1,916件 / Test 1,478件)
- **実験ID**: `vr-si-20261005-103001`
